# Pablo Tuñón Laguna

Engineer in Madrid. I work on computer vision, multi-agent reinforcement learning and real-time robotics, mostly on edge hardware.

Background: Mathematical Engineering and Artificial Intelligence (iMAT), Universidad Pontificia Comillas ICAI, 2022-2026. My bachelor's thesis built a benchmark for coordinating teams of autonomous aerial platforms against wildfires. A policy trained with teams of 3 to 10 drones also solves it with 15, without retraining. The code release is in preparation.
